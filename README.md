# OMNIDASH – High-Fidelity E-Commerce Management System

OMNIDASH is a complete high-fidelity e-commerce application featuring both a customer-facing storefront and a full-featured admin management dashboard.

## Key Flow & Architecture
- **Customer Storefront**: Homepage with Billboard & Curated Categories, Product Detail Page with studio photo gallery & size/color selectors, Shopping Cart, Customer Shipping Information, and Order Confirmation.
- **Sales Receipt Generation**: Built strictly around order placement and formal receipt generation. No online payment gateways (no Stripe/UPI/cards required).
- **Admin Management**: Top metric KPI cards, Revenue analytics, Product management with multi-image gallery uploads, Categories, Sizes, Colors, Billboards, Orders, and Receipts Registry.
- **Multi-Store Management**: Conceptual store selector supporting multiple store instances.

## Quick Start
1. Open `index.html` directly in your browser for the full interactive prototype experience.
2. For Next.js integration, use the typed components in `/components` and `/types`.
